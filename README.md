## 資料集

- 檔案：`data/raw/covid_vaccination_vs_death_ratio.csv`（課程教材雲端提供，原始來源為 Kaggle）
- 21,916 筆、199 個國家，期間 **2020/12/19 ~ 2021/10/26**
- 欄位：`country`、`iso_code`、`date`、`total_vaccinations`、`people_vaccinated`（至少一劑）、`people_fully_vaccinated`（完整接種）、`New_deaths`（當日新增死亡）、`population`、`ratio`（= 至少一劑 / 人口 × 100）

## 分析流程

```
原始資料 → 01 清洗 → 02 EDA → 03 辛普森悖論 → 04 國家分群 → 05 預測模型
```

| 步驟 | 程式 | 做什麼 |
|---|---|---|
| 1 | `src/01_cleaning.py` | 處理負的死亡數、接種率 >100%（直布羅陀）、移除樣本太少的國家、依 ISO 代碼加入洲別、轉成「國家-月份」資料 |
| 2 | `src/02_eda.py` | 全球趨勢、洲別比較、亞洲標竿（新加坡、日本、韓國、馬來西亞） |
| 3 | `src/03_simpson.py` | 辛普森悖論（同月份分洲比較）、反向因果檢查、月份固定效果迴歸 |
| 4 | `src/04_clustering.py` | K-Means 把國家分成 4 類（以輪廓係數、穩定性選 k），提出對應策略 |
| 5 | `src/05_modeling.py` | 迴歸＋分類預測下個月死亡率；比較「時間切」與「國家切」；GridSearchCV 參數優化、依內部驗證選模型；殘差分析、閾值調整、混淆矩陣 |

## 主要發現

**1. 辛普森悖論：同一個月份，全部國家一起看是正相關，分洲看反過來**
- 每個月拿全部國家比較：10 個月中有 9 個月為 **正相關**（中位數 ρ = 0.20），其中 4 個月 p < 0.05——看起來「打越多死越多」
- 同一個月份、只看歐洲內部：10 個月中有 9 個月為 **負相關**（中位數 ρ = −0.31）
- 非洲內部則是正相關（中位數 ρ = 0.37），可能是死亡通報較完整的國家，接種也較多
- 因為是同一個月份內比較，沒有「時間趨勢」的干擾

![](figures/fig04_simpson_scatter.png)

**2. 可能原因：反向因果，或區域、經濟條件的干擾**
- 2021/3 以前死亡率越高的國家，到 2021/5 底接種率越高（全部國家 ρ = 0.43，p = 0.001）
- 但只看歐洲（ρ = 0.22，p = 0.25）或歐洲以外（ρ = 0.34，p = 0.09）都不顯著：整體的相關有一部分只是「歐洲 vs 其他洲」的差異
- 所以這只能支持「先死得多 → 後打得快」的可能，不是定論

**3. 疫苗效果的較強證據：月份固定效果迴歸**
- 模型：`log(1+下月死亡) ~ 本月接種率 + log(1+本月死亡) + 月份虛擬變數 (+ 洲別)`，只拿同一個月份的國家互相比較
- 接種率每 +10 個百分點，下月死亡約 **−1.7%**（控制月份）、**−3.1%**（再控制洲別）；兩者 95% 信賴區間都不包含 0（以國家為單位 bootstrap 500 次）
- 效果方向一致但幅度不大，而且仍可能有未控制的干擾因素（年齡結構、醫療資源）

![](figures/fig06_reverse_causality_fixed_effects.png)

> 補充：同一國家隨時間看，67% 國家接種率與死亡率負相關；接種率突破 50% 後 73% 國家死亡下降。但接種率只會一路上升，這等於在算「死亡 vs 時間」，無法分辨是疫苗效果還是疫情波段剛好過去，因此只作為補充。

**4. 洲別差異**：各國最新接種率的中位數，非洲僅約 9%，歐洲、南美洲已超過 60%

**5. 國家分群（K-Means, k=4）**

| 群組 | 國家數 | 特徵 | 代表國家 | 建議策略 |
|---|---|---|---|---|
| 高接種穩定型 | 47 | 接種率約 67%、推動快 | 新加坡、韓國、日本、西班牙 | 維持追加劑、針對高齡與未接種族群衛教 |
| 高死亡後改善型 | 21 | 前期死亡最高，之後大幅下降 | 葡萄牙、智利、義大利、巴西 | 死亡下降與接種上升同時發生，可作為觀察案例 |
| 接種緩慢型 | 29 | 接種率約 23%，有開打但推不動 | 俄羅斯、羅馬尼亞、印尼、伊朗 | 處理疫苗猶豫：可信任的醫療人員溝通、破除假訊息 |
| 第二劑落後型 | 20 | 平均接種率約 16%，完整接種比例只有 0.43 | 印度、越南、巴基斯坦、埃及 | 提升疫苗供應與可近性、確保第二劑完成 |

k = 4 的分群穩定性中等（ARI 0.65；k = 3 為 0.86），選 k = 4 是為了分出政策意義不同的群組。

**6. 預測模型**
- 迴歸（預測下月死亡率）：線性模型（Linear / Ridge）最好，R² 約 0.66（時間切）/ 0.69（國家切），優於基準模型（下月=本月）的 0.50 / 0.56
- 分類（預測下月死亡是否上升）：AUC 約 0.75 ~ 0.78，優於「延續上月趨勢」基準的 0.62 ~ 0.68
- 參數優化（GridSearchCV，只在訓練集內部驗證）：時間切的 Gradient Boosting R² +0.05、Random Forest 分類 AUC +0.04，其他模型變化在 ±0.01 以內
- 時間切中，依驗證分數選出的 Gradient Boosting 在測試期只有 R² 0.50：測試期遇上 Delta 高峰，複雜模型擬合過度，**簡單的線性模型最穩健**
- 後處理：分類閾值由 0.5 調為 0.3，漏報的疫情上升從 16 個降到 5 個（Recall 0.82 → 0.94）
- 最重要的特徵是「本月死亡數」（疫情有延續性）；拿掉接種特徵後 R² 只下降約 0.01，代表 **短期（一個月）預測主要靠疫情趨勢，接種的效果需要拉長時間才看得出來**

## 研究限制

- 資料只到 2021/10，無法依老師建議以 2021/12 切分，改用 2021/07 切
- 沒有確診數、檢測量、年齡結構、疫苗品牌、變異株（Delta）等資料，無法排除這些干擾因素
- 各國紀錄日期不連續，以「當月平均每日死亡」處理
- 非洲等國死亡通報可能低估，低接種、低死亡不代表疫情輕微
